# URY_RU_EGAIS — алкогольный учёт

Интеграция с ЕГАИС (учёт оборота алкоголя) через УТМ.

## Архитектура

Провайдерный паттерн: `EgaisProvider` → `register_egais_provider()` →
`get_egais_provider()`.

- `egais.py` — интерфейс + реестр
- `drivers/simulated.py` — эмулятор
- `drivers/utm.py` — заглушка УТМ

## Операции

- `get_incoming_waybills()` — входящие ТТН от поставщиков
- `confirm_waybill()` — акцепт ТТН
- `send_outgoing_waybill()` — исходящие ТТН
- `write_off()` — акт списания
- `get_remains()` — остатки по регистру

## Модель данных

- `URY RU EGAIS Settings` (singleton) — провайдер, УТМ, ФСРАР ID, алкогольная продукция
- `URY RU EGAIS Waybill` — журнал ТТН (входящие/исходящие)

## Важно

ЕГАИС работает через **УТМ** (универсальный транспортный модуль) — обязательное
ПО Росалкогольрегулирования на объекте. Наш модуль общается с УТМ, УТМ — с ФСРАР.
