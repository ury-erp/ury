# URY_RU_Marking — маркировка (Честный знак)

Интеграция с национальной системой маркировки «Честный знак» (ЦРПТ).

## ФФД 1.2 (важно)

По решению владельца поддержка **ФФД 1.2** живёт здесь: маркированные товары
требуют формата 1.2 при фискализации. При включении маркировки этот модуль
переключает фискальный формат в `URY RU Fiscal Settings` на 1.2.

## Архитектура

Провайдерный паттерн: `MarkingProvider` → `register_marking_provider()` →
`get_marking_provider()`.

- `marking.py` — интерфейс + реестр
- `drivers/simulated.py` — эмулятор
- `drivers/chestny_znak.py` — заглушка ЦРПТ

## Операции

- `get_codes()` — получение/эмиссия кодов DataMatrix
- `register_emission()` — ввод в оборот
- `aggregate()` — агрегация (короб → паллета)
- `write_off()` — вывод из оборота (продажа/списание)
- `verify()` — проверка кода

## Модель данных

- `URY RU Marking Settings` (singleton) — провайдер, ключи, ИНН, товарные группы
- `URY RU Marking Code` — журнал кодов и их статусов
