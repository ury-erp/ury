# URY_RU_Mercury — ветеринарный учёт

Интеграция с «Меркурий» (подсистема ФГИС «ВетИС», Россельхознадзор) для
учёта продукции животного происхождения.

## Архитектура

Провайдерный паттерн: `MercuryProvider` → `register_mercury_provider()` →
`get_mercury_provider()`.

- `mercury.py` — интерфейс + реестр
- `drivers/simulated.py` — эмулятор
- `drivers/vetis.py` — заглушка ВетИС.API

## Операции

- `get_incoming_vsd()` — входящие ВСД
- `accept_vsd()` — гашение (приёмка)
- `return_vsd()` — возврат
- `create_vsd()` — исходящий ВСД
- `get_products()` — справочник подконтрольной продукции

## Модель данных

- `URY RU Mercury Settings` (singleton) — провайдер, ВетИС.API, ЭЦП
- `URY RU VSD` — журнал ветеринарных сопроводительных документов

## Важно

Обмен идёт через **ВетИС.API** (REST) с ЭЦП. Меркурий обязателен для
ресторанов, работающих с мясом/рыбой/молочкой подконтрольного происхождения.
