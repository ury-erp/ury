# URY_RU_Deepseek — ИИ-аналитика и прогнозы

Модуль интеллектуальной аналитики на базе DeepSeek (OpenAI-совместимый API).
Три функции:

1. **Анализ всех показателей** — сбор метрик (продажи, средний чек, клиенты,
   топ-блюда, кухня) и генерация выводов/советов по управлению.
2. **Прогноз потока посетителей** — загрузка заведения на N дней вперёд.
3. **Прогноз заказа продуктов и полуфабрикатов** — план закупки/приготовления
   для кухни (с раскрытием BOM для полуфабрикатов).

## Архитектура

Провайдерный паттерн (как 1C/Fiscal):

`DeepseekProvider` (интерфейс) → `register_deepseek_provider()` → `get_deepseek_provider()`.

- `deepseek.py` — интерфейс + реестр (NoOp по умолчанию)
- `analytics.py` — сбор показателей из БД (dict)
- `predictions.py` — эвристические прогнозы (скользящее среднее + день недели)
- `drivers/simulated.py` — эмулятор (детерминированный, без API)
- `drivers/deepseek_api.py` — реальный HTTP-клиент DeepSeek
- `doctype/` — настройки, журнал выводов (Insight), журнал прогнозов (Forecast)

## Разделение ответственности

- `analytics.py` / `predictions.py` готовят «сырые» данные из БД.
- Провайдер отвечает за «интеллект»: simulated считает по эвристике,
  deepseek_api отправляет в LLM и разбирает JSON.

## Модель данных

- `URY RU Deepseek Settings` (singleton) — провайдер, API-ключ, модель, периоды
- `URY RU Deepseek Insight` — журнал выводов/советов по анализу
- `URY RU Deepseek Forecast` — строки прогноза (поток / заказ продуктов)

## Расписание

Через `scheduler_events` в `ury_ru/hooks.py` (daily). Анализ пишет строку в
Insight, прогнозы — в Forecast.
