# URY Agent Skills

This directory contains URY-specific skills, scripts, and workflows.

Whenever you learn a new pattern for interacting with the URY app (e.g., running specific browser tests, managing Frappe worktrees, or complex POS build steps), document it here as a skill. 

Agent skills here should be mapped to the global skills available to the agent whenever they overlap (e.g. using standard python/node plugins but with URY-specific contexts).
